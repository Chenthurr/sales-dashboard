# Contributing

The sales dashboard should remain easy to run, understandable, and accurate in its presentation of business metrics.

## Guidelines

- Keep metric calculations deterministic and add regression tests for changed formulas.
- Validate loading, empty-data, and malformed-data states when changing data handling.
- Preserve responsive and accessible dashboard behavior.
- Never commit customer data, credentials, or environment-specific secrets.

## Pull requests

Describe the metric or UI behavior changed and how it was verified. Keep data, presentation, and infrastructure changes focused.
